# Plan: Intégration du module "Exports"

L'objectif est d'ajouter une gestion complète des opérations d'Export dans une vue dédiée, en réutilisant exactement les mêmes fonctionnalités (Opérations, Performance, BCD, Filtres) que pour les Imports.

## 1. Mise à jour des URLs sources (constants.ts)
- Définir `CSV_URL_IMPORTS` avec l'URL actuelle.
- Définir `CSV_URL_EXPORTS` avec la même URL de base en ajoutant le paramètre `&gid=1428313444` (et éventuellement `&single=true` selon le format de publication Google Sheets).

## 2. État Global de l'Application (App.tsx)
- Ajouter un nouvel état global : `const [direction, setDirection] = useState<'import' | 'export'>('import');`
- Modifier la fonction `fetchData` pour qu'elle sélectionne l'URL appropriée (`CSV_URL_IMPORTS` ou `CSV_URL_EXPORTS`) en fonction de l'état `direction`.
- Déclencher un nouveau chargement des données (reset) à chaque changement de `direction`.
- Réinitialiser les filtres lors d'un changement de direction pour éviter des incohérences de données.

## 3. Mise à jour de la Navigation (Header.tsx)
- Ajouter un nouveau sélecteur (Toggle) principal pour basculer entre **Imports** et **Exports**.
  - Emplacement suggéré : À gauche, à côté du logo "GTSM" ou au-dessus des onglets "Opérations / Performance".
- Rendre le titre dynamique : "GTSM Imports" deviendra "GTSM Imports" ou "GTSM Exports" selon la sélection.

## 4. Adaptation des composants (si nécessaire)
- Vérifier que les mots codés en dur (comme "Imports" dans le titre du PDF ou les filtres) s'adaptent dynamiquement au mode en cours, bien que le BCD soit généralement standard.
- S'assurer que le Dashboard Analytics (Performance) gère le changement de dataset sans erreurs.

## Étapes de mise en œuvre
1. Modifier `src/constants.ts` avec les deux URLs.
2. Mettre à jour `src/Header.tsx` pour inclure le nouveau Toggle "Imports / Exports".
3. Mettre à jour `src/App.tsx` pour gérer le nouvel état `direction` et la fonction `fetchData`.
4. Tester le basculement et s'assurer que les données se rafraîchissent correctement avec le nouveau GID.
