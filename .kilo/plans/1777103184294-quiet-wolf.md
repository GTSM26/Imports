# Plan: Gestion des Opérations en MAD

Ce plan vise à permettre la saisie et l'affichage d'opérations vendues directement en Dirhams Marocains (MAD), tout en conservant une analyse globale cohérente dans le tableau de bord.

## 1. Mise à jour du Modèle et des Utilitaires
- **types.ts** : Ajouter une propriété `devise: 'EUR' | 'MAD'` à l'interface `TransportOp`.
- **utils.ts** : Modifier `formatCurrency` pour accepter un code de devise dynamique.
  ```typescript
  formatCurrency(amount: number, currency: string = 'EUR')
  ```

## 2. Évolution du Parsing CSV (App.tsx)
- Modifier la boucle de nettoyage des données pour détecter la devise :
  - Priorité à une colonne `Prix Achat MAD` ou `Vente MAD`. Si remplie, `devise = 'MAD'` et le montant est extrait.
  - Sinon, repli sur `Prix Achat €` avec `devise = 'EUR'`.
  - Supporter également une colonne `Devise` explicite si elle existe dans le Google Sheet.

## 3. Unification des Statistiques Globales
- Pour les KPIs ("C.A. Achat") et les graphiques analytiques, toutes les valeurs seront converties en **EUR** pour permettre l'agrégation.
- **Formule** : Si `devise === 'MAD'`, alors `valeurEUR = prixAchat / parseFloat(eurMadRate)`.
- Cela garantit que les graphiques de "Répartition des Coûts" et le "Coût Moyen" restent comparables.

## 4. Adaptation de la Génération de BCD (pdfGenerator.ts)
- Si l'opération est en MAD (`op.devise === 'MAD'`) :
  - **Masquer** la ligne "Taux de change (BKAM)" car le prix est déjà dans la monnaie locale.
  - Afficher le symbole **MAD** dans le cadre du montant total.
  - Utiliser le montant tel quel sans conversion.
- Si l'opération est en EUR, conserver le comportement actuel (affichage du taux BKAM et symbole €).

## 5. Ajustements UI
- **DataTable.tsx** : Afficher le symbole de la devise correspondante pour chaque ligne.
- **DetailDrawer.tsx** : Afficher le prix avec sa devise d'origine.
- **Analytics** : Préciser dans les tooltips que les montants sont convertis en EUR pour l'analyse globale.

## Étapes de mise en œuvre
1. Modifier `src/types.ts` et `src/lib/utils.ts`.
2. Mettre à jour la logique de parsing dans `src/App.tsx`.
3. Adapter le calcul de `chiffreAchatTotal` dans `App.tsx`.
4. Modifier `src/lib/pdfGenerator.ts` pour gérer les devises.
5. Vérifier l'affichage dans le tableau et le tiroir de détails.
